## Description

Zeus vs Bunnies (Hunted theme)

Extract the archive and run "Hunted" or "Hunted.exe". Shoot stuff.

The game was made in the SpringRTS engine: https://springrts.com/ one week before the warmup weekend and it took us two days to do it. We picked the theme "Hunted/Hunter" for the warmup.

If you find any issues please post on Github: https://github.com/SpringCabal/Hunted/issues
