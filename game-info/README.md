# Original jam entries

Archived information supplied by gajop on 2026-09-11. These are historical
submission descriptions, ratings, credits, controls, and requirements—not
current compatibility advice for the WASM ports. The menu embeds the Description
(About game for Gravitas) and Ratings sections for its left-hand game panel.
After changing scores, run `bash wasm-menu/generate-rating-stars.sh` from the
repository root, then rebuild the menu. Star strips use fractional fills rounded
to the nearest pixel; the numeric scores retain their original precision.
