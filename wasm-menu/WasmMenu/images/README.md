The game/jam associations are documented by a participant in
[Cold Takes: Game Jams](https://www.fightorder.net/wiki/Cold_Takes/19_-_Game_Jams).
[LudumData](https://ludumdata.openfu.com/) records the event dates. Hunted's
original repository starts on August 8, 2015: it was an LD33 warmup, not an
entry in the main jam. Dates in the menu describe the original jam month,
not the later WASM port or inherited repository history. LD43 ran November
30–December 3, 2018; its completion month is displayed.

Direct original entry links are still pending verification. The menu's
current system-control API does not expose browser opening.
